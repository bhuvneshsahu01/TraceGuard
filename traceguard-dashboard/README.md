# 📊 TraceGuard Analytics Dashboard

**The Real-Time UI for TraceGuard Agent Observability.**

This Next.js (React 19) Dashboard is the nerve center of TraceGuard. It visualizes the raw OpenTelemetry traces emitted by your Python SDKs, turning raw telemetry into actionable Latency Heatmaps, Drift Charts, and FinOps analytics.

## Getting Started

First, ensure you have a `traceguard.db` file (automatically generated by running any agent instrumented with `traceguard-sdk`) in the root directory.

Then, install dependencies and generate the Prisma client:

```bash
cd traceguard-dashboard
npm install
npx prisma generate
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Architecture & Features

The dashboard uses Next.js `App Router`, `SWR` for real-time local polling, and `Recharts` for high-performance data visualization.

- **FinOps ROI Metrics**: Aggregates the API cost of your agent tools against their success rate, helping you deprecate expensive tools that don't solve tasks.
- **Latency Heatmaps**: A scatter plot identifying outlier execution times (e.g. rate limits or long generation times).
- **Trace Waterfalls**: A Datadog-style trace visualization graph that maps out every nested Swarm interaction, RAG retrieval, and Tool call in chronological order.
- **Drift Charts**: Real-time line graphs showing evaluation stability (via PSI) over time.

## Deployment

The easiest way to deploy your TraceGuard dashboard is to use the [Vercel Platform](https://vercel.com/new). 

**Note**: To deploy serverlessly to Vercel, you should migrate the underlying database from SQLite to a hosted PostgreSQL/MySQL instance (such as Supabase or Neon). Update the `provider` in `prisma/schema.prisma` and redeploy!
